# Synapbiz.Brain.Authoring

The headless half of Brain MCP: seventeen tools as plain functions (JSON in, JSON out, a JSON Schema each) that let an assistant read approved processes and rules, work on drafts, simulate made-up cases, and write proposals. No model, no network, no MCP SDK.

- Every answer carries `say`, a sentence in English or Spanish that can be told to a person as it is.
- Nothing changes an approved document; a draft is ready only when Brain's own checks say so.
- Reference: `docs/reference/brain-authoring.md` in the repository.
