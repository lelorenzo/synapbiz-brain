# Synapbiz.Brain.Mcp

Adapts the Brain authoring tools to the Model Context Protocol with the official C# SDK: `services.AddMcpServer().WithBrainAuthoring(options)` adds the tools, the guide resources and the prompt `model_a_process_with_me` to an MCP server a host already builds. The host supplies the store, catalog, clock and authorization.

Reference: `docs/reference/brain-mcp.md` in the repository.
