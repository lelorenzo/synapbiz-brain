# Changelog

## Unreleased

- W-B: `Synapbiz.Brain.Workbench.Blazor`, the rule workbench panels as a Razor class library whose only public component is `RuleWorkbench`: rule list, Read, Simulate (with a per-row explanation and the engine refusal in words), Test cases (with a form to propose a case), Review and export of `brain.rule-review@1` files through a host callback. The host supplies rules, locale, a `WorkbenchSession` it owns, a clock and an optional export callback; fixed strings come from `WorkbenchStrings` (Spanish and English, 193 keys, overridable except that the four markings are never emptied); the stylesheet reads only `--wb-*` tokens. Also `RuleLabels.ValueFormatter` in `Synapbiz.Brain.Workbench`. 201 bUnit tests, 4 coupling tests and the purity scan extended to the new assembly; a demo host in `samples/` with a Playwright screenshot script. Docs: `docs/reference/rule-workbench-panels.md`. The solution now packs five packages.
- W-A: `Synapbiz.Brain.Workbench`, a headless rule workbench for `brain.rule@1`. Plain-language rule views with one sentence per row in English and Spanish (templates of the source repository's sentence generator, labels from `meta.display`), fact input parsing with typed error codes, simulation on the real engine with a per-row explanation, test runs with extra cases, revision diff and behaviour comparison, and the `brain.rule-review@1` review document. 299 tests on synthetic fixtures (`tests/fixtures/workbench`), purity scan and reference freeze extended to the new library. Docs: `docs/reference/rule-workbench.md`. The solution now packs four packages.

## 0.1.0 (2026-11-22)

- Release workflow publishing to the private GitHub Packages feed on a version tag, a manual live-parity workflow, and the consumer guide (`docs/consuming.md`).
- B0 PR 1: `brain-engine`. The Decision Engine cores move into this repository as `Synapbiz.Brain.Contracts` (28 files, `BrainException`, `ContentHash`) and `Synapbiz.Brain.Engine` (14 files), with the engine unit tests, architecture guards (BCL-only references, no package references, engine purity), the source drift guard and the live and baseline behaviour parity proofs, and CI.
- B0 PR 2: `brain-spec` for rules. `Synapbiz.Brain.Spec` reads module contracts, loads and validates `brain.rule@1` documents against them with the source repository's codes, paths and messages, projects them to a decision table and golden cases, and runs them on the engine with the document version on the trace. 77 rule conformance cases, a purity scan extended to constructors and type initializers and to the new library, a second drift-guard section for 7 data files, and the `spec/` parity scenarios (310 entries: the 77 rule cases and 38 structure documents; the 364 earlier entries are unchanged). Docs: the rule reference and the interim-shape migration guide. The solution now packs three packages.
